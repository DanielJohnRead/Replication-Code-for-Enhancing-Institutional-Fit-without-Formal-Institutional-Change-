This repository contains replication R code and data for the paper "Enhancing Institutional Fit without Formal Institutional Change" published in Ecology and Society in 2026 by Daniel J. Read, Alexandra Carroll, and Lisa Wainger (https://doi.org/10.5751/ES-16912-310109). Descriptions of the data and analysis can be found in the article.

Data are anonymized
